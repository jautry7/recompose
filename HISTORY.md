# Project history

## Historical provenance

Recompose began as an exploratory research project before its Git repository was created. Its initial commit sequence was assembled afterward from preserved source files, file modification times, diagnostic results, generated manifests, screenshots, and contemporaneous development notes.

These commits reproduce the supported chronological progression of the work. Their author dates correspond to the best available timestamp for each milestone; their committer dates record when the Git history was assembled. When an exact intermediate source snapshot was not preserved, the corresponding state was reconstructed from the observed behavior and the known change that followed it.

Accordingly, the initial sequence should be understood as a documented reconstruction of the project's development—not a claim that every intermediate file survived byte-for-byte. The commit titled `chore: begin ordinary repository history` marks the transition to normal, contemporaneous commits.
